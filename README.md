# Performance Bottleneck Analytics

*Developed by Ritu Raj Singh*

## Project Overview

This project analyzes system performance from a business perspective, focusing on latency, errors, conversion, abandonment, and the financial impact of performance problems.

The objective is to identify performance bottlenecks and provide measurable insights that can support engineering prioritization.

## Business Objective

* Analyze system latency and error rates
* Understand their relationship with conversion and abandonment
* Quantify potential revenue impact
* Compare performance across regions and platforms
* Identify high-impact performance bottlenecks
* Prioritize areas where performance improvements may provide business value

## Data Preparation

The raw dataset was cleaned using *Excel*. The cleaning process included duplicate removal, missing-value handling, data-type validation, standardization, and basic data-quality checks.

The cleaned dataset was then used for analysis and Tableau visualization.

## Analysis

Python was used for data analysis and calculation of business metrics including:

* Conversion Rate
* Abandonment Rate
* Error Rate
* Average Latency
* Revenue Impact
* Profit
* Platform Performance
* Regional Performance
* Latency Bands
* Bottleneck Priority

The analysis results were organized into a single output file for easy review.

## Tableau Dashboard

The Tableau dashboard provides an interactive view of:

* Performance KPIs
* Latency and Conversion
* Platform Performance
* Regional Performance
* Monthly Performance
* Revenue Impact
* Bottleneck Priority

Filters allow performance to be explored by date, region, platform, and version.

## Tools & Technologies

* Excel — Data Cleaning
* Python — Data Analysis
* Pandas & NumPy — Data Processing
* Tableau — Visualization & Dashboard
* GitHub — Project Documentation

## Business Value

The project connects technical performance metrics with business outcomes. It helps identify areas where latency and errors are associated with lower conversion, higher abandonment, and potential revenue impact.

## Conclusion

This project demonstrates an end-to-end analytics workflow from *Excel data cleaning to Python analysis and Tableau dashboard development*, with a focus on measurable performance and business impact.
